옵션 동선 플레이북

마지막 확인: 2026-05-15

목적: 기본 4박 5일 루트는 유지하되, 예약 성공/실패, 컨디션, 날씨, 식욕, 맥주/라멘/돈카츠 욕심에 따라 어떤 옵션을 켜고 무엇을 빼야 하는지 정리한다.

기본 원칙

옵션은 추가가 아니라 교체다.

좋아 보이는 후보를 계속 붙이면 일정이 망가진다. 옵션을 하나 켜면 반드시 아래 셋 중 하나가 빠져야 한다.

  • 같은 시간대의 기본 식사
  • 같은 날의 2차/술
  • 다음 날의 무거운 후보

옵션 우선순위

우선순위옵션켜는 조건끄는 조건
1예약 대박Sushi Yuuki, Torishige, Sake Labo, L'ETERRE 같은 예약이 실제로 잡혔을 때예약 없거나 취소정책/예산이 애매할 때
2고점 시도 슬롯Tonta, Hotate Biyori처럼 당일 조건이 좋을 때 대박인 곳줄/등록시간/피로가 기본 앵커를 위협할 때
3분위기 루트Yamane -> Nagi -> OPEN BOOK처럼 재미와 분위기가 목적일 때진짜 미식 저녁을 먹고 싶은 날
4맥덕 루트선토리 푸어링/맥덕 목적이 그날의 주제가 될 때Sake Labo, 스시, Torishige 같은 메인 저녁이 있는 날
5숙소권 회복피곤하거나 비/더위/짐 때문에 멀리 가기 싫을 때이미 예약된 강한 식사가 있을 때

L'ETERRE/화요일 고급 예약방 사케 밤고급 저녁과 방 사케 밤은 같은 저녁 시간을 두고 경쟁한다.
수요일 Kyorakutei 보강Tsujita와 불필요한 산책공항일에는 가벼운 보강 하나만 넣을 수 있다.

1일차 선택 동선

토요일 A - Tonta 시도

다음 조건일 때 사용:

  • 입국과 짐 맡기기가 순조롭다.
  • 체력이 좋다.
  • 16:45-17:10 전후 Tonta에 도착할 수 있다.

동선:

Amber -> AFURI Harajuku -> Meiji Jingu 가벼운 산책 -> Tonta -> Amber

추가하지 말 것:

  • Tonta가 유난히 빨리 끝나고 체력이 아주 좋지 않은 한, Tonta 뒤 Yamane Shoten은 넣지 않는다.
  • 13:00 이후 커피.

토요일 B - 도착일 회복

다음 조건일 때 사용:

  • 입국심사/수하물/이동이 느리다.
  • Amber 도착이 14:00-15:00 이후다.
  • 날씨가 나쁘거나 잠을 잘 못 잤다.

동선:

Amber -> AFURI or simple local meal -> short walk -> early sleep

좋은 대체안:

  • Tsujita Iidabashi.
  • 아주 쉬운 동네 술집이 필요할 때만 Sakegura Torichu나 Sanma를 쓴다.

이유:

  • 첫날을 이기는 것보다 여행 전체를 살리는 것이 낫다.

2일차 선택 동선

일요일 A - Hotate 시도

다음 조건일 때 사용:

  • 오전 일정이 제때 흘러간다.
  • 기명/입장 시스템이 깔끔한 점심 슬롯을 준다.
  • 배정된 점심 시간이 Master's Dream이나 Sake Labo를 위협하지 않는다.

동선:

Apollon's Gold -> Hotate Biyori -> Marunouchi -> Master's Dream -> Sake Labo

중단 기준:

  • 점심 시간이 13:15 이후로 밀리면 Hotate를 생략한다.

일요일 B - Sake Labo 보호 모드

다음 조건일 때 사용:

  • Hotate가 번거로워 보인다.
  • 날씨나 몸 상태가 무겁다.
  • Sake Labo가 확정되어 보호해야 한다.

동선:

Apollon's Gold -> 가벼운 Marunouchi/Ginza -> IMADEYA 구경 -> Master's Dream 한 잔 -> Sake Labo

이유:

  • Hotate가 없어도 여전히 아주 강한 날이다.

일요일 C - Sake Labo 없는 일요일

다음 조건일 때 사용:

  • Sake Labo가 월요일에만 예약되거나, 일요일 예약이 실패했다.

동선:

Apollon's Gold -> 조건부 Hotate -> IMADEYA -> Master's Dream -> Iidabashi 근처 가벼운 저녁

그다음:

  • 예약이 잡히면 Sake Labo를 월요일로 옮긴다.
  • 월요일 스시/Torishige/Shinjuku는 뺀다.

3일차 선택 동선

월요일 A - 스시 대박

다음 조건일 때 사용:

  • Sushi Yuuki 또는 더 강한 스시 취소석이 예약됐다.

동선:

가벼운 하루 -> 스시 -> 복귀

추가하지 말 것:

  • Ramen Nagi.
  • Yamane.
  • 예약이 늦고 식욕이 아주 좋을 때가 아니면 RAMEN MATSUI 점심.

월요일 B - Torishige 진지한 신주쿠 저녁

다음 조건일 때 사용:

  • 스시 예약이 실패했다.
  • Torishige가 예약됐거나 전화로 확인됐다.

동선:

가벼운 하루 -> Torishige -> 조건부 Golden Gai 한 잔

이유:

  • 스시를 제외하면 가장 강한 신주쿠 저녁이다. 음식 근거로는 캐주얼 영상 루트보다 낫다.

월요일 C - 신주쿠 분위기 동선

다음 조건일 때 사용:

  • 진지한 예약이 없다.
  • 카카오/유튜브에서 본 신주쿠 분위기를 원한다.
  • 신주쿠 골목을 다닐 체력이 충분하다.

동선:

Yamane Shoten -> Ramen Nagi -> The OPEN BOOK

규칙:

  • Yamane은 일찍 닫으므로 먼저 간다.
  • 배고플 때만 Nagi를 넣는다.
  • OPEN BOOK은 짧은 2차일 뿐 필수는 아니다.

월요일 D - Beer Geek 동선

다음 조건일 때 사용:

  • 월요일에 스시/Torishige/Sake Labo가 예약되지 않았다.
  • 그날 밤의 주제를 맥주로 정했다.

가장 좋은 버전:

Iidabashi -> Ryogoku -> Beer Club POPEYE -> Iidabashi

or

Iidabashi -> Shimbashi DRY-DOCK -> Brasserie Beer Blvd. -> Iidabashi

이유:

  • Beer Club POPEYE는 탭 다양성이 넓은 진짜 맥덕 목적지이고 월요일-토요일 영업한다.
  • 탭 개수보다 깔끔한 푸어링 비교가 목적이면 DRY-DOCK/Beer Blvd.가 낫다.

함께 넣지 말 것:

  • Sushi Yuuki.
  • Torishige.
  • Sake Labo.

월요일 E - 숙소권 회복

다음 조건일 때 사용:

  • 2일차가 무거웠다.
  • 예약 실패.
  • 여행에 숨 쉴 틈이 필요하다.

동선:

Iidabashi/Kagurazaka simple 저녁 -> early night

좋은 선택지:

  • Tsujita if ramen mood.
  • Sake Bar Otonari if nearby 사케 mood.
  • Sanma or Torichu if you want simple local izakaya.

4일차 선택 동선

화요일 A - 기본 방 사케

기본으로 사용한다.

동선:

Kyorakutei -> 휴식 -> Daimaru/Gransta 안주 -> Hasegawa 냉장 사케 -> Amber

그래도 가장 깔끔한 4일차다.

화요일 B - 돈카츠 보강

다음 조건일 때 사용:

  • Tonta가 실패했다.
  • 그래도 진지한 돈카츠 기억을 남기고 싶다.
  • 점심이 더 무거워져도 괜찮다.

동선:

Tonkatsu Kenshin -> 휴식 -> 더 가벼운 도쿄역 장보기 -> 방 사케

바뀌는 점:

  • Skip Kyorakutei.
  • 방 사케 안주는 더 가볍게: 튀김류보다 사시미/스시 + 절임류.

화요일 C - 라멘 보강

다음 조건일 때 사용:

  • Hotate가 실패했고 라멘 욕심이 남았다.
  • 도시를 가로지르는 고위험 줄서기는 원하지 않는다.

동선:

Sanntora or Tsujita -> 도쿄역 -> 방 사케

RAMEN MATSUI가 예약되면:

RAMEN MATSUI -> rest -> 도쿄역 -> 방 사케

바뀌는 점:

  • Skip Kyorakutei.
  • 라멘 점심이 무거우므로 사케 저녁은 더 가볍게 둔다.

화요일 D - 하이엔드 대체

다음 조건일 때 사용:

  • L'ETERRE, Kasahara, Ishikawa, Kohaku, Shinohara 또는 그에 준하는 강한 예약이 잡혔다.
  • 예산과 취소 조건이 괜찮다.

동선:

가벼운 점심 -> 휴식 -> 고급 저녁

바뀌는 점:

  • 방 사케 밤은 빼거나 늦은 작은 병/간식으로만 축소한다.
  • Kyorakutei와 무거운 방 사케 장보기를 같이 하지 않는다.

화요일 E - 추가 맥주 동선

다음 조건일 때만 사용:

  • 월요일을 조용히 보냈다.
  • 맥주 중심 스톱을 하나 더 넣고 싶다.
  • 방 사케를 줄여도 괜찮다.

가장 좋은 버전:

Kyorakutei -> 휴식 -> The PREMIUM MALT'S HOUSE 또는 Kagurazaka ARBOL -> 작은 방 사케

이유:

  • POPEYE/Shimbashi보다 가까운 곳에서 맥주 보강을 끝낸다.
  • 그래도 방 사케라는 아이디어를 지킨다.

5일차 선택 동선

5일차 옵션은 의도적으로 매우 제한한다.

수요일 A - 기본 안전 출국

Luggage solved -> Tsujita -> local walk -> Nippori 16:25/16:45 Skyliner -> NRT T3

수요일 B - Kyorakutei 보강

다음 조건일 때만 사용:

  • 화요일 Kyorakutei가 실패했다.
  • 짐 문제가 해결됐다.
  • 11:20까지 도착할 수 있고 줄이 짧다.

수요일 C - Tonkatsu Kenshin 보강

다음 조건일 때만 사용:

  • Tonta가 실패했다.
  • 여유로운 공항일보다 돈카츠가 더 중요하다.
  • 13:00-13:30까지 끝낼 수 있다.

사용하지 말 것:

  • 시내를 가로지르는 목적지형 일정.
  • Tsujita나 간단한 동네 식사가 아닌데 13:00 이후 시작하는 식사.

날씨/체력 모드

악천후 / 더위 모드

기본 변경:

  • Reduce Meiji Jingu.
  • Skip Tonta unless energy is high.
  • Prefer Iidabashi/Kagurazaka/도쿄역 indoor/short-hop blocks.
  • Sake Labo와 방 사케는 예약/계획되어 있으면 유지한다.

가장 좋은 동선 형태:

토요일 local easy
일요일 Apollon's Gold -> Marunouchi -> Sake Labo
월요일 예약 또는 숙소권
화요일 방 사케
수요일 공항 안전 모드

고에너지 모드

두 사람 모두 컨디션이 좋을 때만 사용:

  • 토요일 Tonta try.
  • 일요일 Hotate 시도.
  • 월요일 예약 또는 신주쿠 분위기 동선.

고에너지 모드에서도:

  • 스시와 라멘을 겹치지 않는다.
  • Sake Labo와 맥주 크롤을 겹치지 않는다.
  • 수요일을 목적지형 일정으로 만들지 않는다.

저에너지 모드

가장 좋은 동선 형태:

토요일 숙소권 회복 루트
일요일 Apollon's Gold -> Master's Dream short -> Sake Labo
월요일은 숙소권 또는 예약 하나만
화요일 방 사케
수요일 Tsujita -> 공항

그래도 여행의 질은 충분히 유지된다.

결정 트리

  1. Sake Labo가 일요일에 예약됐는가?
  • 예: 일요일을 보호한다. Hotate는 시간이 깔끔할 때만.
  • 아니오, 월요일은 예약됨: 월요일은 Sake Labo. 스시/Torishige/Shinjuku는 삭제.
  • 아니오: 일요일은 맥주/사케숍/가벼운 저녁으로 쓰고 월요일 예약 사다리를 유지한다.
  1. Sushi Yuuki가 월요일에 예약됐는가?
  • 예: 월요일은 Sushi Yuuki 하나에 집중.
  • 아니오: Torishige를 확인.
  1. Torishige가 확정됐는가?
  • 예: 월요일은 Torishige.
  • 아니오: 신주쿠 분위기, 맥덕 루트, 숙소권 회복 루트 중 선택.
  1. 토요일에 Tonta가 성사됐는가?
  • 예: 돈카츠 미션은 더 넣지 않는다.
  • 아니오: Kenshin을 화요일/수요일 조건부 보강으로 둔다.
  1. 일요일에 Hotate가 성사됐는가?
  • 예: 라멘 미션 완료.
  • 아니오: RAMEN MATSUI/Sanntora/Tsujita는 나중에 쓰되 교체로만 사용.
  1. 화요일 저녁이 아직 비어 있는가?
  • 예: 방 사케 밤을 유지.
  • 아니오: 고급 예약이 이기면 방 사케는 빼거나 아주 작게 줄인다.

현재 추천

기본 루트를 유지한다. 적극적으로 볼 만한 옵션은 다음 정도다:

  1. 월요일 Sushi Yuuki 또는 더 강한 스시 예약.
  2. Sake Labo 일요일/월요일 예약 결과.
  3. 월요일 안 B로 Torishige.
  4. 토요일 Tonta는 도착 컨디션이 아주 좋을 때만.
  5. Hotate Biyori는 입장 시간이 깔끔할 때만.
  6. Tonta가 실패했을 때 보강용 Tonkatsu Kenshin.
  7. Beer Club POPEYE 또는 Shimbashi DRY-DOCK/Beer Blvd.는 월요일에 진지한 예약이 없고 맥주가 그날의 분위기가 될 때만.

나머지는 첫 번째 일정 안에 숨어 있는 두 번째 일정이 아니라, 회복용 또는 날씨 백업으로만 둔다.
