Optional Route Playbook

Last checked: 2026-05-15

Purpose: 기본 4박 5일 루트는 유지하되, 예약 성공/실패, 컨디션, 날씨, 식욕, 맥주/라멘/돈카츠 욕심에 따라 어떤 옵션을 켜고 무엇을 빼야 하는지 정리한다.

Core Rule

Options are swaps, not add-ons.

좋아 보이는 후보를 계속 붙이면 일정이 망가진다. 옵션을 하나 켜면 반드시 아래 셋 중 하나가 빠져야 한다.

  • 같은 시간대의 기본 식사
  • 같은 날의 2차/술
  • 다음 날의 무거운 후보

Day 1 Optional Routes

Sat A - Tonta Try

Use when:

  • Arrival and luggage drop are smooth.
  • Energy is good.
  • You can reach Tonta around 16:45-17:10.

Route:

Amber -> AFURI Harajuku -> Meiji Jingu light walk -> Tonta -> Amber

Do not add:

  • Yamane Shoten after Tonta unless Tonta is unusually fast and energy is unusually high.
  • Coffee after 13:00.

Sat B - Arrival Recovery

Use when:

  • Immigration/luggage/transport is slow.
  • You arrive at Amber after 14:00-15:00.
  • Weather is bad or sleep is poor.

Route:

Amber -> AFURI or simple local meal -> short walk -> early sleep

Good replacements:

  • Tsujita Iidabashi.
  • Sakegura Torichu or Sanma only if you want a very easy local drink.

Why:

  • Saving the trip is better than winning the first night.

Day 2 Optional Routes

Sun A - Hotate Attempt

Use when:

  • Morning is on time.
  • The entry/registration system gives a clean lunch slot.
  • Assigned lunch time does not threaten Master's Dream or Sake Labo.

Route:

Apollon's Gold -> Hotate Biyori -> Marunouchi -> Master's Dream -> Sake Labo

Kill switch:

  • If lunch time drifts after 13:15, skip Hotate.

Sun B - Sake Labo Protection Mode

Use when:

  • Hotate looks annoying.
  • Weather or body feels heavy.
  • Sake Labo is confirmed and should be protected.

Route:

Apollon's Gold -> light Marunouchi/Ginza -> IMADEYA browse -> Master's Dream 1 beer -> Sake Labo

Why:

  • This is still a very strong day without Hotate.

Sun C - No Sake Labo Sunday

Use when:

  • Sake Labo can only be booked Monday, or fails Sunday.

Route:

Apollon's Gold -> optional Hotate -> IMADEYA -> Master's Dream -> light dinner near Iidabashi

Then:

  • Move Sake Labo to Monday if booked.
  • Drop Sushi/Torishige/Shinjuku from Monday.

Day 3 Optional Routes

Mon A - Sushi Jackpot

Use when:

  • Sushi Yuuki or stronger sushi cancellation is booked.

Route:

Light day -> Sushi -> return

Do not add:

  • Ramen Nagi.
  • Yamane.
  • RAMEN MATSUI lunch unless reservation is late and appetite is excellent.

Mon B - Torishige Serious Local

Use when:

  • Sushi fails.
  • Torishige is reserved or phone-confirmed.

Route:

Light day -> Torishige -> optional one short Golden Gai drink

Why:

  • This is the strongest non-sushi Shinjuku dinner. It beats the casual video route for food evidence.

Mon C - Shinjuku Mood Route

Use when:

  • No serious reservation.
  • You want the Kakao/YouTube feeling.
  • Energy is good enough for Shinjuku alleys.

Route:

Yamane Shoten -> Ramen Nagi -> The OPEN BOOK

Rules:

  • Yamane first because it closes early.
  • Nagi only if hungry.
  • OPEN BOOK is a short 2차, not a must.

Mon D - Beer Geek Route

Use when:

  • Sushi/Torishige/Sake Labo are not booked for Monday.
  • You decide beer is the theme of the night.

Best versions:

Iidabashi -> Ryogoku -> Beer Club POPEYE -> Iidabashi

or

Iidabashi -> Shimbashi DRY-DOCK -> Brasserie Beer Blvd. -> Iidabashi

Why:

  • Beer Club POPEYE is a true beer-geek destination with broad tap variety and is open Mon-Sat.
  • DRY-DOCK/Beer Blvd. is better if the goal is clean pouring comparison rather than tap count.

Do not combine with:

  • Sushi Yuuki.
  • Torishige.
  • Sake Labo.

Mon E - Local Recovery

Use when:

  • Day 2 was heavy.
  • Reservations failed.
  • You need the trip to breathe.

Route:

Iidabashi/Kagurazaka simple dinner -> early night

Good options:

  • Tsujita if ramen mood.
  • Sake Bar Otonari if nearby sake mood.
  • Sanma or Torichu if you want simple local izakaya.

Day 4 Optional Routes

Tue A - Default Room Sake

Use by default.

Route:

Kyorakutei -> rest -> Daimaru/Gransta food -> Hasegawa chilled sake -> Amber

This is still the cleanest Day 4.

Tue B - Tonkatsu Catch-Up

Use when:

  • Tonta failed.
  • You still want a serious tonkatsu memory.
  • You are willing to make lunch heavier.

Route:

Tonkatsu Kenshin -> rest -> lighter Tokyo Station basket -> room sake

What changes:

  • Skip Kyorakutei.
  • Make room sake food lighter: sashimi/sushi + pickles, not fried foods.

Tue C - Ramen Catch-Up

Use when:

  • Hotate failed and ramen desire remains.
  • You do not want a high-risk city-crossing queue.

Route:

Sanntora or Tsujita -> Tokyo Station -> room sake

If RAMEN MATSUI is reserved:

RAMEN MATSUI -> rest -> Tokyo Station -> room sake

What changes:

  • Skip Kyorakutei.
  • Keep sake dinner lighter because ramen lunch is heavier.

Tue D - High-End Override

Use when:

  • L'ETERRE, Kasahara, Ishikawa, Kohaku, Shinohara, or another genuinely strong reservation is booked.
  • Budget and cancellation terms feel fine.

Route:

Light lunch -> rest -> high-end dinner

What changes:

  • Drop room sake night or turn it into a tiny late bottle/snack only.
  • Do not also do Kyorakutei + heavy room basket.

Tue E - Extra Beer Route

Use only if:

  • Monday stayed quiet.
  • You still want one more beer-focused stop.
  • Room sake can be reduced.

Best version:

Kyorakutei -> rest -> The PREMIUM MALT'S HOUSE or Kagurazaka ARBOL -> smaller room sake

Why:

  • This keeps the extra beer closer than POPEYE/Shimbashi.
  • It still protects the room-sake idea.

Day 5 Optional Routes

Day 5 options are very limited by design.

Wed A - Default Safe Departure

Luggage solved -> Tsujita -> local walk -> Nippori 16:25/16:45 Skyliner -> NRT T3

Wed B - Kyorakutei Catch-Up

Use only if:

  • Tuesday Kyorakutei failed.
  • Luggage is solved.
  • You can arrive by 11:20 and line is light.

Wed C - Tonkatsu Kenshin Catch-Up

Use only if:

  • Tonta failed.
  • Tonkatsu still matters more than a relaxed airport day.
  • You can finish by 13:00-13:30.

Do not use:

  • Any destination across town.
  • Any meal that begins after 13:00 unless it is Tsujita/simple local.

Weather And Energy Modes

Bad Weather / Heat Mode

Default change:

  • Reduce Meiji Jingu.
  • Skip Tonta unless energy is high.
  • Prefer Iidabashi/Kagurazaka/Tokyo Station indoor/short-hop blocks.
  • Keep Sake Labo and room sake if booked/planned.

Best route shape:

Sat local easy
Sun Apollon's Gold -> Marunouchi -> Sake Labo
Mon reservation or local
Tue room sake
Wed airport-safe

High Energy Mode

Only use if both people feel good:

  • Sat Tonta try.
  • Sun Hotate attempt.
  • Mon reservation or Shinjuku mood.

Even in high energy mode:

  • Do not stack sushi + ramen.
  • Do not stack Sake Labo + beer crawl.
  • Do not make Wed a destination day.

Low Energy Mode

Best route shape:

Sat local recovery
Sun Apollon's Gold -> Master's Dream short -> Sake Labo
Mon local or one reservation only
Tue room sake
Wed Tsujita -> airport

This still keeps the trip good.

Decision Tree

  1. Is Sake Labo booked Sunday?
  • Yes: protect Sunday. Hotate only if clean.
  • No, but Monday is booked: Monday becomes Sake Labo. Drop Sushi/Torishige/Shinjuku.
  • No: use Sun as beer/sake-shop/light dinner and keep Mon reservation ladder.
  1. Is Sushi Yuuki booked Monday?
  • Yes: Mon is Sushi Yuuki only.
  • No: check Torishige.
  1. Is Torishige confirmed?
  • Yes: Mon is Torishige.
  • No: choose Shinjuku mood, beer geek, or local recovery.
  1. Did Tonta happen Saturday?
  • Yes: no more tonkatsu mission.
  • No: Kenshin becomes a Tue/Wed optional catch-up.
  1. Did Hotate happen Sunday?
  • Yes: ramen mission done.
  • No: RAMEN MATSUI/Sanntora/Tsujita can be used later, but only as a swap.
  1. Is Tuesday still free?
  • Yes: keep room sake night.
  • No: if a high-end reservation wins, drop room sake or make it tiny.

Current Recommendation

Keep the default route. The only options worth actively watching are:

  1. Sushi Yuuki or stronger sushi reservation for Monday.
  2. Sake Labo Sunday/Monday booking result.
  3. Torishige as Monday Plan B.
  4. Tonta on Saturday only if arrival condition is excellent.
  5. Hotate Biyori only if the entry time is clean.
  6. Tonkatsu Kenshin as catch-up if Tonta fails.
  7. Beer Club POPEYE or Shimbashi DRY-DOCK/Beer Blvd. only if Monday has no serious reservation and beer becomes the mood.

Everything else should be kept as a recovery or weather fallback, not a second itinerary hiding inside the first one.
